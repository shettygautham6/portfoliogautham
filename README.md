# Gautham Originals Portfolio

A fully interactive, Netflix-inspired personal portfolio website built for Gautham R Shetty.

## Deployment to GitHub Pages

1. **Create a new repository** on GitHub (e.g., `my-portfolio` or `gautham-portfolio`).
2. **Upload these files** (`index.html`, `extracted_files/Gautham_Resume.pdf`, etc.) to the root of your repository on the `main` or `master` branch.
3. Go to your repository **Settings** -> **Pages**.
4. Under **Build and deployment**, set the **Source** to `Deploy from a branch`.
5. Select your branch (`main`/`master`) and folder (`/ (root)`), then click **Save**.
6. Your portfolio will be live at `https://<your-username>.github.io/<repository-name>/` within a minute!
